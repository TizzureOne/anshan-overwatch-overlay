# 安山守望

用于《守望先锋》教学的 Windows 桌面标注工具，支持英雄拖放、战术绘图和 OBS 透明输出。

## 下载

[版本下载](https://github.com/TizzureOne/anshan-overwatch-overlay/releases)

两种安装包功能相同：

- 完整版：自带运行组件，直接安装使用。
- 精简版（文件名含 Lite）：下载更小，需要 [.NET 8 Desktop Runtime 和 ASP.NET Core Runtime](https://dotnet.microsoft.com/zh-cn/download/dotnet/8.0)，均选 Windows x64。缺少时安装程序会提示并提供下载入口。

安装后从开始菜单启动。免安装版解压后双击 `AnshanOverlay.exe`。

英雄资料默认在启动时独立更新，也可在“设置 → 英雄数据”手动检查，无需重装或重启；断网或更新失败时沿用已有资料。

## 使用

1. 在浮条“··· → 场景与教学屏幕”选择教学屏幕；场景、设置和 OBS 帮助也从“···”进入。
2. 点击“英雄”，选择蓝方或红方，双击头像添加到战术板中央，或拖出放置。开启“批量添加”可一次添加多位英雄。
3. 用工具栏绘制线条、箭头、椭圆、矩形或文字，用移动工具调整标注，用橡皮擦除。
4. 点击“战术模式 / 桌面模式”，或按 `Ctrl+Alt+E` 切换。战术模式用于标注，桌面模式可操作下方的游戏或回放。

浮条上的“英雄”“工具”“战术板”分别控制对应内容的显示。点击 Logo 可恢复工具；窗口右上角“×”只关闭该窗口，退出程序请用浮条或托盘菜单。

| 默认快捷键 | 操作 |
|---|---|
| Ctrl+Alt+E | 战术模式 / 桌面模式 |
| Ctrl+Alt+P | 恢复面板与工具栏 |
| Ctrl+Alt+T | 画布置顶 |
| Ctrl+Alt+H | 显示 / 隐藏标注 |

鼠标停在工具上可查看快捷键，在“更多操作”中可自定义。如果点不到后面的窗口，按 `Ctrl+Alt+E` 返回桌面模式。

- 多选：使用移动工具（`V`），`Shift+点击` 加选或取消，从空白处拖动框选。拖动选区可整体移动，`Delete` 删除，`Ctrl+D` 复制，`Ctrl+Z` 撤销。右键已选头像可批量修改英雄阵营、尺寸或删除。
- 文字：选择文字工具（`T`）后点击战术板输入。Enter 换行，点击空白或 Ctrl+Enter 完成，Esc 取消；双击已有文字继续编辑。每段最多 500 字、12 个手动换行的文本行，草稿不进入 OBS。
- 临时画笔：将画笔的“保留”切换为“5 秒”，松手 5 秒后笔迹自动消失。
- 英雄轨迹：右键头像，或选中后在工具栏“所有英雄轨迹”中选择虚线、拖尾或关闭，保留时长为 1–10 秒。设置对所有英雄生效；轨迹和临时笔迹同步到 OBS，不写入场景。

场景自动保存，也可手动保存和加载；每个场景最多 2000 个对象。数据位于 `%LOCALAPPDATA%\AnshanOverlay`，卸载后保留。可读取旧场景；新保存的场景需要 0.1.14-beta 或更新版本打开，回退前请保留旧场景备份。

## 更新与动效

在“设置”中检查、下载和安装软件更新。默认启动时及每隔 12 小时检查，Beta 默认接收测试版，可改为只接收正式版。更新保留完整版或精简版的类型，断网时可继续使用当前版本。

“设置 → 网络代理”支持跟随系统、不使用代理或手动 HTTP、HTTPS、SOCKS5 代理，不支持账号密码。保存后用于后续软件更新、安装包下载和英雄资料更新，无需重启。

设置中可关闭界面动效、自定义英雄选中标记；这些效果不进入 OBS。“场景”页可调整桌面模式下英雄头像及名称的透明度，默认 50%，不影响 OBS。可选的“高帧率模式（目标 60 FPS）”会增加资源占用，实际帧率取决于硬件与场景。

## OBS

1. 在“OBS / 帮助”复制地址。
2. 在 OBS 添加“浏览器”源，粘贴地址，宽高填写面板显示的画布尺寸。
3. 将标注源放在游戏或视频源上方，对齐位置、缩放和裁剪。

浏览器源输出英雄与标注。使用“显示器捕获”时，直接录制桌面标注即可。

## 开发

环境：Windows、.NET 8 SDK；制作安装包使用 [Inno Setup 6.7+](https://jrsoftware.org/isdl.php)。在仓库根目录运行：

```powershell
dotnet build src/AnshanOverlay/AnshanOverlay.csproj -c Release
./tools/test.ps1
./tools/publish.ps1 -CompilerPath "C:\Program Files (x86)\Inno Setup 6\ISCC.exe"
./tools/publish.ps1 -Lite -CompilerPath "C:\Program Files (x86)\Inno Setup 6\ISCC.exe"
```

`src/AnshanOverlay/` 为应用源码，`tools/` 为素材、测试和打包脚本；安装包输出到 `dist/`，测试结果输出到 `artifacts/qa/`。

英雄素材及组件来源见 [第三方声明](THIRD-PARTY-NOTICES.md)。
