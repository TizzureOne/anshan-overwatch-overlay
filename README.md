# 安山守望

用于《守望先锋》教学的 Windows 桌面标注工具。拖放英雄头像、绘制战术路线，通过 OBS 输出透明标注。

当前版本：**0.1.14-beta（测试版）**。

## 下载

[版本下载](https://github.com/TizzureOne/anshan-overwatch-overlay/releases) · Windows 10/11 x64

同一个版本提供两种安装包，功能相同：

- **完整版**：自带所需运行组件，适合直接安装使用。
- **精简版（文件名含 Lite）**：省去运行组件，下载更小。需要 [.NET 8 Desktop Runtime 和 ASP.NET Core Runtime](https://dotnet.microsoft.com/zh-cn/download/dotnet/8.0)，均选择 Windows x64；缺少时安装程序会列出所缺组件，并提供官方下载入口，补齐后再继续。

安装后从开始菜单启动。免安装版解压后双击 `AnshanOverlay.exe`。程序内置 54 位英雄头像（含血律），黑影位于“支援”分类。

英雄数据可独立于软件版本更新。在“设置 → 英雄数据”点击“检查英雄数据更新”，或保留默认开启的“启动时自动更新英雄数据”。程序直接核对暴雪官方名单与国服名称，只下载新增或变更的头像，更新后立即同步英雄库、画布和 OBS，无需重装或重启。设置分别显示软件版本和英雄资料日期。官方两份名单尚未同步、断网或下载失败时继续使用已有资料；旧英雄 ID 保留，避免影响保存的教学场景。更新缓存保存在 `%LOCALAPPDATA%\AnshanOverlay\hero-data.zip`，下次可离线使用。

## 使用

启动后，上方是带原有 Logo 的讲解浮条，下方是绘图工具栏。“英雄”“工具”“战术板”三个开关分别控制英雄库、绘图工具与战术内容是否显示，开启时高亮。关闭工具不会关闭英雄库，Logo 始终保留，点击 Logo 可恢复工具。两条浮条均可拖动，讲解浮条可调整宽度，窄窗自动分成两行。

英雄库关闭再打开保留当前搜索、分类和批量选择。输入搜索时自动检索全部英雄；可用 `Ctrl+F` 聚焦搜索。场景、OBS / 帮助与设置放在独立的“设置与场景”窗口，从浮条“···”进入；打开它不会切走英雄库。有软件更新时，“···”显示为“更新”。

1. 在浮条“··· → 场景与教学屏幕”选择教学屏幕。
2. 点击“英雄”，选择蓝方或红方，双击头像即可在战术板中央添加并进入战术模式，也可拖出自由放置。拖放结束恢复原来的模式。选中英雄默认显示青绿色四角标记，可在工具栏或右键菜单修改英雄属性。
3. 用工具栏绘制线条、箭头、椭圆和矩形；用移动工具调整标注，用橡皮擦擦除局部。
4. 直接点击浮条上的“战术模式 / 桌面模式”，或按 `Ctrl+Alt+E` 切换。战术模式用于摆英雄和绘图，桌面模式让鼠标操作下方的游戏或回放。

拖动窗口空白处可移动面板和工具栏，拖动边缘可调整尺寸。英雄库和工具栏支持折叠。英雄库及设置窗口右上角“×”只关闭对应窗口，旧版保存的“退出程序”偏好不再影响这些按钮。退出程序请使用浮条或系统托盘中的明确退出入口。

工具栏会根据宽度、当前工具及选中对象的参数计算最低高度。变窄、切换工具或选中英雄时自动补足高度，避免按钮换行后把参数挤到窗口外；仍可继续拉高窗口。标题统一为“工具”。

在“设置 → 英雄选中样式”中选择四角、圆环、准心或隐藏标记，可调整颜色（预设色或 `#RRGGBB`）、粗细、间距、线段长度、不透明度及深色衬边。亮、暗背景同步预览，点击“应用样式”立即生效并保存；“恢复默认”还原全部选项。圆环不使用线段长度。这些设置只改变本机选中反馈，不改变阵营颜色，也不进入场景或 OBS 输出。

战术模式下点击战术板会出现短暂的柔和光波，返回桌面模式后清除。点击“安山守望”Logo 会有轻微转动反馈，并保留恢复工具的作用；快速连续点击五次会触发“英雄集结”横幅、旋转徽章、扩散光圈和彩纸，约 2.8 秒后自动收起，鼠标可穿过特效继续操作。点击特效与 Logo 动画遵循界面动效及 Windows 动画设置。

讲解浮条、英雄库、设置和工具栏固定在战术板上方，切换模式或画布置顶后仍保持；取消画布置顶时，控制窗口继续置顶。按 `Ctrl+Alt+P` 恢复浮条、英雄库与工具栏，并恢复窗口顺序。

正常退出时会记住讲解浮条的位置、宽度和工具收起状态，以及绘图工具栏的位置与大小。英雄库在需要时于浮条附近打开；显示器变化导致位置越界时会放回可见区域。升级时将旧版默认的大面板调整为紧凑尺寸，保留自定义尺寸。

| 默认快捷键 | 操作 |
|---|---|
| Ctrl+Alt+E | 战术模式 / 桌面模式 |
| Ctrl+Alt+P | 恢复面板与工具栏 |
| Ctrl+Alt+T | 画布置顶 |
| Ctrl+Alt+H | 显示 / 隐藏标注 |

鼠标停在工具上可查看快捷键，在“更多操作”中可自定义。窄工具栏将直线、箭头、椭圆和矩形收进形状菜单；常规宽度会全部展开。

讲解浮条和英雄库显示当前模式；战术模式下，画布左下角也显示模式与快捷键。如果点不到后面的窗口，可点击“战术模式”切回桌面模式，按 `Ctrl+Alt+E`，或在空白处右键选择“退出战术模式”。空白处菜单也提供英雄库、开启/关闭英雄名显示、工具、画笔、箭头、撤销和保留英雄的清笔迹操作。英雄名开关同步到 OBS，也可撤销。

画布声明为桌面叠加窗口，以兼容 Windows 自动隐藏任务栏；移到任务栏所在的屏幕边缘时应可正常唤出。画布尺寸和 OBS 对齐方式保持不变。

在独立窗口“场景”页调整“桌面模式时的图标透明度”，范围 0–100%，默认 50%。只调整桌面模式的英雄头像及名称，不改变线条、文字和轨迹；进入战术模式后恢复图标原透明度。0% 隐藏图标，100% 保持原样。设置保存在本机，OBS 浏览器源不受影响。

批量添加：开启英雄库的“批量添加”，点选英雄后按“添加”。可跨职责和搜索选择，添加后整组移动。

多选与框选：使用“移动”工具（`V`），`Shift+点击` 加选或取消；从空白处拖动，框与英雄头像接触即可选中，其他标注需完全框入，`Shift+框选` 追加。拖动已选对象可整体移动，`Delete` 删除，`Ctrl+D` 复制，`Ctrl+Z` 撤销整次操作。右键任一已选头像，可批量修改这些英雄的阵营、尺寸或删除；混合选中的线条等标注保持不变。右键未选中的头像时，只处理该头像。

点击空白清除选择；`Esc` 依次取消当前操作、清除选择、进入桌面模式。

场景自动保存，也可在“场景”中手动保存和加载。数据位于 `%LOCALAPPDATA%\AnshanOverlay`，卸载后保留。

文字标注：点击工具栏“文字”（`T`），再点击战术板，在该位置直接输入；可选择颜色和字号，文字带深色底。Enter 换行，点击空白、✓ 或按 Ctrl+Enter 完成，Esc 或 × 放弃本次修改。每段最多 500 字、12 个手动换行的文本行，超出宽度会自动折行。窄工具栏仍可直接选择文字工具。

完成后文字自动选中，可直接拖动；双击已有文字，或选中后点击工具栏“编辑文字”，可在原位置继续编辑。每次完成编辑只占一步撤销；清空已有文字并完成会删除它。支持调整字号、不透明度、多选移动、复制、删除、撤销与重做。橡皮对文字始终整项擦除。输入框中的打字、删除和文字撤销不会触发画布快捷键。

完成的文字随场景自动保存，并按桌面的换行同步到 OBS 浏览器源；输入框和未完成的草稿不进入 OBS。切换工具、返回桌面模式或主动保存时会完成当前输入。编号工具及其快捷键已移除，旧场景中的已有编号仍可读取、显示和删除。场景保存使用第 4 版格式，新版可读取第 1–3 版场景；新保存的场景需要本版或更新版本打开。

临时画笔：在“画笔”参数区将“保留”切换为“5 秒”，笔迹会在松开鼠标 5 秒后自动消失，桌面和 OBS 同步清除；选择“永久”即可恢复普通画笔。默认选择“永久”，仅影响画笔。临时笔迹不写入场景，也不进入永久撤销历史；撤销优先移除仍在显示的临时笔迹，重做只在原来的 5 秒期限内有效。切换工具后继续计时，成功加载场景、切换屏幕、清除标注或退出程序会清除临时笔迹。英雄、文字、编号及永久图形保持原有保存方式。

英雄移动轨迹：右键画布上的任一英雄头像，在菜单中直接选择“关闭”“虚线”或逐渐变细淡出的“拖尾”，用下方滑块调整保留时长（1–10 秒，默认 3 秒）。此设置对所有英雄生效，选择样式或调整时长时菜单保持打开。拖动头像时，轨迹跟随实际移动路径，颜色跟随蓝方或红方；多选移动时每位英雄分别留下轨迹。每段轨迹从经过时开始计时，停住或松手后继续消失，桌面与 OBS 同步。功能默认关闭，开关、样式与时长会保存在本机。轨迹不写入场景，不可选中，也不占撤销步骤；撤销仍直接撤回英雄移动。关闭或调整轨迹设置、取消当前拖动、撤销重做、清除标注、成功加载场景、切换屏幕或退出时会清理对应轨迹。

选中英雄后，也可从工具栏“所有英雄轨迹”调整样式和时长；调整期间菜单保持依附在按钮旁。切换工具、收起、移动或改变工具栏宽度时会关闭旧菜单。

每个场景最多容纳 2000 个对象；达到上限时会提示先删除部分内容，批量添加和复制不会只完成一部分。加载损坏或不支持的场景会保留当前内容并显示错误；无法读取的设置会回退到默认值。复制靠近画布边缘的对象时会向可见区域偏移。

## 更新与动效

在“设置”页可手动检查、查看新版说明、下载并安装。默认在启动时及每隔 12 小时后台检查，有新版时在面板提示；下载完成并校验通过后，保存场景、退出、安装并重新打开。更新保留完整版或精简版的类型，下载途中可以取消。

Beta 默认接收测试版更新，可取消勾选以只接收正式版。网络不可用时可继续使用当前版本，也可打开下载页手动安装。

在“设置 → 网络代理”选择“跟随系统”（默认）、“不使用代理”或“手动代理”。手动代理填写如 `http://127.0.0.1:7890` 或 `socks5://127.0.0.1:1080`，点击“保存代理设置”；支持 HTTP、HTTPS 和 SOCKS5，不支持账号密码。地址和端口应与自己的代理软件一致。设置会保存，下次软件更新检查、安装包下载及英雄资料更新立即采用新配置，无需重启；正在进行的请求沿用原设置，可取消后重试。可以点击“检查软件更新”验证连接。“打开下载页”使用浏览器自身设置，OBS 本机服务不受此选项影响。

界面参考 [Microsoft Fluent 2](https://fluent2.microsoft.design/motion) 与 [Windows 菜单规范](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/menus)，统一按钮、英雄卡片、选项、滑块、下拉框和提示框。英雄右键菜单按身份、阵营、尺寸和删除分组，阵营与尺寸直接点选。

按钮按压、英雄筛选与入场光圈、选中反馈、面板淡入淡出、模式与开关高亮、工具参数切换、折叠展开、菜单逐项出现与悬停反馈均有短时动效。快速反向切换会取消旧动画，拖动、画线和滑块仍实时响应。可在“设置”页关闭动效，也遵循 Windows 动画设置；桌面界面动效不写入场景、不进入 OBS 浏览器源。

“高帧率模式（目标 60 FPS）”位于设置页，默认关闭。开启后将轨迹刷新和 OBS 同步从约 30 次/秒提高到约 60 次/秒，即时生效并保存；会增加资源占用，实际帧率取决于硬件与场景。虚线轨迹从旧到新擦除，未过期虚线的位置保持固定；拖尾保留渐细淡出的表现。

## OBS

1. 在“OBS / 帮助”复制地址。
2. 在 OBS 添加“浏览器”源，粘贴地址，宽高填写面板显示的画布尺寸。
3. 将标注源放在游戏或视频源上方，对齐位置、缩放和裁剪。

浏览器源输出英雄与标注。使用“显示器捕获”时，直接录制桌面上的标注即可。

## 开发

环境：Windows、.NET 8 SDK；制作安装包使用 [Inno Setup 6.7+](https://jrsoftware.org/isdl.php)。在仓库根目录运行：

```powershell
dotnet build src/AnshanOverlay/AnshanOverlay.csproj -c Release
./tools/test.ps1
./tools/publish.ps1 -CompilerPath "C:\Program Files (x86)\Inno Setup 6\ISCC.exe"
./tools/publish.ps1 -Lite -CompilerPath "C:\Program Files (x86)\Inno Setup 6\ISCC.exe"
```

`src/AnshanOverlay/` 包含应用、头像与 OBS 页面；`tools/` 包含素材生成、测试和打包脚本。安装包输出到 `dist/`，测试结果输出到 `artifacts/qa/`。

英雄素材及组件来源见 [第三方声明](THIRD-PARTY-NOTICES.md)。
